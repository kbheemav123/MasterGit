# MasterGit

This is a practice git repo to learn about github:
Will do some git commits in local command prompt to practice

Some Notes:

Commit:
What does commit mean? In context of git you are commiting changes to either create, delete or update files or folders in the repo.

A good commit has the right changes and the right commit messages.
git status: Displays current state of repo
git add: Add a file
git diff: Find changes

Only want to add first change or decide what to include? git add -p file
You will get an yes or no options of diff chunks and asked if want to include, if chosen yes then included if chosen no other parts are saved for next commit

Commit messages:
Subject: Cocise summary
Body: More detailed explanation: what is it, what is diff than before, what is the reason for the changes and is there anything to watch out for.

git init: Initializes a new local repo
git push: Sends commits ti the remote
git pull: Fetches and integrates remote changes
git branch: lists local branches
